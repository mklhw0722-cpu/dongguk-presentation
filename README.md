## 2. 슬라이드 구성 (총 10장 · 5분 분량)

1. **슬라이드 01** — 표지 및 발표 4대 구성 (WHY · HOW · CHALLENGES · VISION) `[20초]`
2. **슬라이드 02** — WHY 1 : 교육학과 구성원이 겪는 3가지 문제 (정보의 분산 · 정보 격차 · 졸업생 연결 약화) `[40초]`
3. **슬라이드 03** — WHY 2 : 세 가지 문제를 잇는 하나의 해답 (‘정보의 통합 · 경험의 공유 · 구성원 간 연결’) `[20초]`
4. **슬라이드 04** — HOW 1 : 개발 기술 4가지 및 현재 구현한 기능 5가지 (`✓ 구현 완료`) `[40초]`
5. **슬라이드 05** — HOW 2 : 동국e음 실제 서비스 화면 삽입 슬라이드 (로그인/승인 화면 · 실시간 채팅 화면) `[25초]`
6. **슬라이드 06** — HOW 3 : 향후 개발할 기능 6가지 (`🚀 개발 예정`) `[55초]`
7. **슬라이드 07** — CHALLENGES ①·② : 회원 인증의 정확성 & 졸업생의 지속적인 참여 (문제 ➔ 해결 방향) `[50초]`
8. **슬라이드 08** — CHALLENGES ③·④ : 실시간 채팅 관리 & 정보 정확성과 유지보수 (문제 ➔ 해결 방향) `[50초]`
9. **슬라이드 09** — VISION 1 : 분리되어 있던 6대 요소가 ‘동국e음’으로 연결되는 다이어그램 `[10초]`
10. **슬라이드 10** — VISION 2 : 최종 슬로건 및 마무리 (‘선배의 경험이 후배의 자산이 되는 공간, 동국e음’) `[10초]`
